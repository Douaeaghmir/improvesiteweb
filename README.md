# À propos du projet
Voici mon projet concernant Élan Fitness. L'objectif est de transformer l'ancien site monopage en un site à plusieurs pages, afin que les informations soient mieux organisées et plus faciles à trouver.
# Pages
Home: To introduce the gym and show the main information.
Programs: To show the different gym programs and coaches.
About: To present the gym, its values and the team.
Contact: To show the contact information and allow visitors to send a message.
# Technologies utilisées
HTML pour la structure du site web.
CSS pour le design et le style.
Git et GitHub pour sauvegarder mon travail et suivre les modifications.
GitHub Pages pour publier le site en ligne.
# Fonctionnalités
Navigation entre les différentes pages.
Un design simple et clair.
Différentes sections pour les programmes d'entraînement et les coachs.
Une page de contact.
